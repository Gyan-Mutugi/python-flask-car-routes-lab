# Introduction to Flask - Car Routes

## Description
This application builds custom routes for a car company database using Flask[cite: 7, 5]. It features a default root route and a dynamic model route to check vehicle availability[cite: 7, 5].

## Features
- **Default Route (`/`)**: Returns a welcome message introducing Flatiron Cars.
- **Model Route (`/<model>`)**: Checks if the requested car model exists in the catalog and returns the appropriate fleet status message[cite: 4].
